LangGraph 기반 AI 보고서 자동 생성기 구축
노드(Node)·엣지(Edge)·상태(State) 기반 시각적 워크플로 오케스트레이션 파이프라인 설계
강의 과정: AX Essential - AI 어시스턴트와 자동화 (L2. 연습) 실습 세션: 2.2 LangGraph로 워크플로 자동화
스크립트 파일: langgraph_report_generator.py 실행 런타임: Ubuntu (OCI) | Python 3.12 (ai-venv) | gpt-5-nano

1. 실습 개요 및 워크플로 목표

• 실습 주제: LangGraph를 활용한 "주제 리서치 → 핵심 요약 → AI 보고서 자동 완성" 워크플로 설계

• 설계 의도: 단순 선형 체인을 넘어 각 단계를 독립된 Node로 모듈화하고 StateGraph를 통해 상태(State)를 안전하게 전달하는 비선형 에이전트 워크플로 구축.

• 개발 환경: 로컬 IntelliJ 작성 → GitHub Actions CI/CD → 원격 Ubuntu 서버(Python 3.12, ai-venv, gpt-5-nano) 자동 배포 및 구동.

2. LangGraph 4대 핵심 아키텍처 요소

구성 요소 역할 및 비즈니스 로직 구현 방식 및 기술 스택
Graph State 전체 파이프라인을 관통하며 노드 간에 전달되는 데이터 스키마(주제, 조사 결과, 최종 보고서) 관리 TypedDict 기반의 ReportState 정의
Research Node 입력된 주제(Topic)에 대해 산업 동향 및 핵심 기술 요소를 다각도로 심층 조사 llm.invoke() 기반 research_node 함수
Summary Node 조사된 방대한 데이터를 구조화된 비즈니스 브리핑 보고서 포맷으로 압축 요약 보고서 규격 프롬프트 적용 summary_node 함수
Edge & Runner 시작(START) → Research → Summary → 종료(END) 간 데이터 흐름 정의 및 그래프 컴파일 StateGraph.add_edge() 및 app.invoke()

3. 실행 코드 구현 (langgraph_report_generator.py)

import os from typing import TypedDict from dotenv import load_dotenv from langchain_openai import ChatOpenAI from langchain_core.prompts import PromptTemplate from langchain_core.output_parsers import StrOutputParser from langgraph.graph import StateGraph, START, END load_dotenv() llm = ChatOpenAI(model="gpt-5-nano", temperature=0.2) class ReportState(TypedDict): topic: str research_result: str final_report: str def research_node(state: ReportState) -> dict: prompt = PromptTemplate.from_template("IT 수석 연구원 관점에서 2026 최신 트렌드를 조사하세요:\n\n주제: {topic}") chain = prompt | llm | StrOutputParser() return {"research_result": chain.invoke({"topic": state["topic"]})} def summary_node(state: ReportState) -> dict: prompt = PromptTemplate.from_template("조사 결과를 바탕으로 [핵심 요약 3줄 + 실행 전략] 보고서를 작성하세요:\n\n{research_result}") chain = prompt | llm | StrOutputParser() return {"final_report": chain.invoke({"research_result": state["research_result"]})} workflow = StateGraph(ReportState) workflow.add_node("research", research_node) workflow.add_node("summary", summary_node) workflow.add_edge(START, "research") workflow.add_edge("research", "summary") workflow.add_edge("summary", END) app = workflow.compile() if __name__ == "__main__": final_output = app.invoke({"topic": "2026년 생성형 AI 및 멀티에이전트 오케스트레이션 트렌드"}) print(final_output["final_report"])

5. 분석 결론 및 시사점

💡 "Chain에서 Graph로의 진화: AI 오케스트레이터 역량 확보" 결론
1. 상태(State) 중심 설계: 이전 노드의 결과가 유실되지 않고 그래프 컨텍스트 내에서 엄격하게 관리되어 복합 보고서의 논리적 일관성이 크게 향상됨.
2. 모듈화 및 확장성: 향후 검증(Validation) 노드, 데이터베이스 저장 노드, 슬랙 알림 노드 등을 그래프 엣지(Edge)로 손쉽게 추가할 수 있는 확장성을 확보함.
3. 시사점: AI 엔지니어의 역할은 프롬프트 작성을 넘어, 업무 프로세스를 노드와 데이터 흐름으로 모델링하는 시스템 아키텍트(Orchestrator)로 진화함.
